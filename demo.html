Tenant 0 · Demo data

See the team in action

One workflow we run on ourselves: research → page → social → short video → outreach use → measure. No invented revenue. If a count appears, it is labeled Demo data.

  1. Demo data

    1 · Research

    Trigger
    Weekly topic pass for Tenant 0 — Teamulate marketing itself.
    Agents
    Intelligence, then Head of Marketing.
    Outputs
    A brief and a recommended page angle. No traffic claims.
    QA
    Checks the brief against brand rails and what we will not claim.
    Direction
    Strategos locks the angle before the page gets written.
    Launch
    None. A brief is not a live page.
    Next action
    Page draft.

  2. Demo data

    2 · Page

    Trigger
    Approved brief from the research pass.
    Agents
    Content, Search / GEO, Web / CRO.
    Outputs
    A page draft in the queue.
    QA
    Voice, rails, and no invented proof.
    Direction
    Inside the strategy Strategos set.
    Launch
    Wordsmith and Web ship the page.
    Next action
    Social cut-downs from the same brief.

  3. Demo data

    3 · Social

    Trigger
    Approved page or page draft marked ready to cut.
    Agents
    Content, Creative Studio.
    Outputs
    Socialite publishes the cut-downs from the brief.
    QA
    Claims and brand.
    Direction
    Inside the strategy Strategos set.
    Launch
    Posts go out on the channels in the plan.
    Next action
    Short video from the same angle.

  4. Demo data

    4 · Short video

    Trigger
    Approved social angle.
    Agents
    Creative Studio.
    Outputs
    A short-cut draft. No view counts here.
    QA
    Brand and claims.
    Direction
    Inside the strategy Strategos set.
    Launch
    Cine ships the cut.
    Next action
    Outreach that uses the page, post, and cut.

  5. Demo data

    5 · Outreach use

    Trigger
    Approved assets from the page / social / video steps.
    Agents
    Demand, Lifecycle.
    Outputs
    An outreach draft that points at the live or approved work.
    QA
    No invented lift. No guaranteed ROI.
    Direction
    Inside the strategy Strategos set.
    Launch
    Lifecycle and GrowthTrack run the outreach.
    Next action
    Measure what the tools recorded.

  6. Demo data

    6 · Measure

    Trigger
    The cycle has something to observe — or it is still empty.
    Agents
    Analytics, Head of Marketing.
    Outputs
    A report of what your tools recorded. Empty is allowed.
    QA
    No invented ROI. No guaranteed lift.
    Direction
    Strategos reads the report and sets the next pass.
    Launch
    None. Measure reports what the tools recorded.
    Next action
    Improve, then the next research pass.
